# NotoSansJP-Regular.ttf / NotoSansJP-Bold.ttf

Noto Sans JP — Google LLC.
配布元: https://fonts.google.com/noto/specimen/Noto+Sans+JP
（SIL Open Font License 1.1 の下で再配布可能）

`@fontsource/noto-sans-jp` パッケージが提供する日本語サブセットの woff2 を
fonttools で TrueType(.ttf) に変換して同梱している（内容は同一フォント）。

日本語を含む天気予報画像（`src/services/weatherImage.ts`）をどの実行環境でも
文字化けなく描画できるよう、システムフォントに依存せずこのフォントを同梱しています。
